# Tiny Pixel Editor

A minimal pixel-art editor built with Python and Pygame.

## Features

- Click-to-draw
- Color palette
- Undo / Redo
- Clear canvas
- Save artwork as PNG

## Controls

- Mouse Click → Draw
- Z → Undo
- Y → Redo
- C → Clear
- S → Save Image

## Run Locally

Install dependencies:

pip install -r requirements.txt

Run:

python main.py
